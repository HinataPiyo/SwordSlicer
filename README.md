# SwordSlicer

**剣をブン回して、ブーメランのように飛ばせ！**

SwordSlicerは、剣をドラッグして回転させ、指やボタンを離して敵へ投げる防衛アクションゲームです。ドラッグ中に蓄積する回転量が投擲後のカーブと攻撃間隔に影響します。敵の動きに合わせた投げ方と、強化項目の組み合わせを工夫して、迫り来る敵から防衛ラインを守りましょう。

> 本READMEは現在のソースコードとUnity設定をもとに、確認できた機能を説明しています。企画上のアイデアと実装済みの機能を区別し、未確認の項目は記載していません。

## ゲームの特徴

### 回して投げる剣の操作

剣を押さえてドラッグすると、剣は最初に押した位置を中心に回転します。指を離すと、直前のドラッグ方向へ剣が飛び出します。ドラッグ中に蓄積した回転量は投擲後のカーブに反映されるため、回転のさせ方と投げる方向の両方が攻撃の狙いを左右します。

### 回転量が攻撃頻度につながる

攻撃間隔は剣の回転量が大きいほど短くなり、設定された下限より短くはなりません。実装では瞬間的な回転速度ではなく、ドラッグ操作などで蓄積した回転量を使います。攻撃力だけでなく回転やカーブの強化も活用し、連続攻撃を狙えるのが本作の特徴です。

### 強化を解放して、自分好みに調整

敵を倒して得た通貨で強化項目を解放できます。投げる力・曲がる力・曲がる反応時間・攻撃範囲は、解放後にレベルを上下して現在値を調整できます。攻撃力やクリティカルなど、その他の項目は強化ボタンからレベルを上げる方式です。数値を自由入力する機能ではありません。

### 行動の異なる敵

敵はまっすぐ進むだけでなく、ジャンプ中は攻撃を受け付けないものや、側面・背後からの攻撃が必要なものもいます。敵の行動や位置を見て、投擲のタイミングと軌道を工夫しましょう。

## 操作方法

操作にはUnity Input Systemを使用します。入力アクションにはマウス専用の入力とPointer向けの入力が登録されています。

| 操作 | 動作 |
| --- | --- |
| 剣の近くを押してドラッグ | 剣を操作します。ドラッグ中は剣が画面上の剣操作エリア内でポインターに追従します。 |
| 押した位置の周りを回すようにドラッグ | 押した位置を中心とする角度の変化が回転量として蓄積されます。 |
| ドラッグしたまま方向をつけ、指／ボタンを離す | 直前のドラッグ方向へ剣を投げます。蓄積した回転量に応じて飛行方向がカーブします。 |
| 「剣を取る」ボタンを押す | 剣のストックがある場合、次の剣を受け取ります。投げた剣は帰還せず、一定時間後に消えます。 |

## ステータス・強化

ホーム画面の強化UIでは、通貨を使って強化レベルを解放します。解放済みのレベル範囲内で一部項目を調整し、ゲーム内の値に反映できます。

| 強化項目 | 確認できる効果 |
| --- | --- |
| 攻撃力 | 敵に与える基本ダメージを上げます。 |
| 投げる力 | 投擲時の剣の移動速度に影響します。投擲速度はドラッグ時間にも応じて変化します。 |
| 曲がる力 | 投擲後の軌道の曲がり方と、蓄積可能な回転量に影響します。 |
| 曲がる反応時間 | 蓄積した回転量に剣の進行方向が追従する速さを調整します。 |
| 攻撃範囲 | 敵への攻撃判定の範囲に影響します。剣の表示サイズにも使われます。 |
| クリティカル率 | クリティカル攻撃の発生率を上げます。 |
| クリティカルダメージ倍率 | クリティカル時のダメージ倍率を上げます。 |
| 鍛造間隔 | 次の剣がストックに追加される間隔を短くします。 |
| ストック数 | 保持できる剣の数を増やします（設定上の上限は5本です）。 |

レベルを上下して値を調整できるのは「投げる力」「曲がる力」「曲がる反応時間」「攻撃範囲」です。攻撃力、クリティカル率、クリティカルダメージ倍率、鍛造間隔、ストック数にはその調整UIはなく、強化レベルを上げる方式です。強化値と通貨はホーム画面から手動で保存でき、ローカルのセーブデータに記録されます。

## 敵

ゲームの敵出現スケジュールに登録された種類と、敵の挙動スクリプトから確認できる特徴を記載しています。敵の種類は出現経過時間に応じて解放されます。

| 敵 | 実装で確認できる特徴 |
| --- | --- |
| スライム（2種） | 防衛ラインに向かって直線的に移動します。 |
| ゴブリン（2種） | クールダウンを挟み、目標ラインに向かって距離を詰めます。 |
| ゾンビ | ダメージを受けると一定時間無敵になり、その間は移動も停止します。 |
| カエル | ジャンプを繰り返し、ジャンプ中は攻撃が当たりません。 |
| トロール | 正面からの攻撃を防ぎ、側面または背後からの攻撃を受け付けます。 |
| ミノタウロス | ゴブリンと共通の移動処理を使い、間を置いて目標へ移動します。 |
| キノコ | 時間経過後に胞子から子キノコを出現させます。 |
| デビル | その場にとどまり、火の玉を出現させます。 |
| 火の玉 | デビルから出現し、上下に波打つ軌道で防衛ラインへ進みます。 |

スライム・ゴブリンは出現データにそれぞれ2種登録されています。火の玉は通常の出現スケジュールではなく、デビルが生成する敵として実装されています。

## ゲームの進行

- `HomeScene`からゲームモード選択や強化などを行い、`GameScene`で防衛プレイを開始します。
- 敵は時間経過とともに出現間隔やステータスが変化し、難易度設定はイージー、ノーマル、ハード、エクストリーム、ナイトメアの5段階です。
- 剣は攻撃間隔に応じて攻撃状態となり、攻撃範囲内に敵がいれば攻撃します。命中時はダメージ表示、効果音、カメラシェイク、攻撃エフェクトが発生し、クリティカル時は専用の表示になります。
- 敵が防衛ラインに到達するとゲームオーバーになり、結果画面に防衛時間、撃破数、最大ヒット数、獲得通貨などが表示されます。
- セーブ画面から手動で保存・ロードできます。セーブデータには通貨、強化レベル、音量設定が含まれます。ゲーム終了時の自動保存は実装上確認できません。

## 技術構成

- Unity Editor: `6000.3.15f1`（`ProjectSettings/ProjectVersion.txt`）
- 言語: C#
- 描画: Universal Render Pipeline 2D（URP）
- 入力: Input System `1.19.0`
- UI: UI Toolkit（UXML／USS）
- その他の主要パッケージ: Cinemachine `3.1.7`
- 外部ライブラリ: Unityroomクライアント（`com.unityroom.client`）

Android用とWeb Desktop Development用のBuild Profileがプロジェクトにあります。これはビルド設定ファイルの存在を示すもので、各プラットフォームでの実行・ビルドを本作業で検証したものではありません。

## 実行方法

1. Unity HubでこのリポジトリのフォルダーをUnityプロジェクトとして開きます。
2. `ProjectSettings/ProjectVersion.txt`に記載されたUnity Editor `6000.3.15f1`を使用します。
3. Unity Editorで`Assets/Scenes/HomeScene.unity`を開き、Playを実行します。

ビルド対象シーンの設定では、`HomeScene`が先、`GameScene`が次の順に登録されています。必要なパッケージは`Packages/manifest.json`に基づきUnityが解決します。ビルドや実機での実行確認は、このREADME作成時には行っていません。
