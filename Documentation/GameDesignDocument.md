# SwordSlicer ゲームデザイン・体験設計

## 1. デザインの読み取り

### コンセプト（実装からの整理）

プレイヤー自身が剣をドラッグして回転させてから投げ、移動軌道と攻撃テンポを作る防衛サバイバル。剣の操作そのものを攻撃手段とし、敵の位置・行動に合わせたタイミングと軌道選択を求める。

これはコードから説明できるコンセプトの要約であり、未発見の企画書に記された開発者の正式な企画意図とは区別する。

## 2. コアゲームプレイ

1. 剣の近くを押してドラッグ開始。
2. 剣を操作可能エリア内で移動させ、円運動などで回転量を作る。
3. 離す直前の位置サンプルから飛行方向を求め、ドラッグ時間から投擲速度を決める。
4. 回転量に追従して飛行方向を滑らかに変え、攻撃周期ごとに周囲の敵を判定する。
5. 敵の弱点や無敵タイミングに合わせて撃破し、強化通貨を獲得する。
6. 敵の出現頻度・能力が上がる中で、防衛ライン到達まで生存する。

操作入力・移動・攻撃はそれぞれ [SwordControl.cs](../Assets/Scripts/Sword/SwordControl.cs) と [SwordAttack.cs](../Assets/Scripts/Sword/SwordAttack.cs) に分かれている。ドラッグ位置サンプルを最大0.3秒保持し、そのうち直近0.1秒に近い位置との差で方向を求める。サンプルが得られない場合は開始点からの差分を使い、方向がほぼゼロなら上向きを採用する。

## 3. ゲームの基本ループと選択

- **戦闘中**：ストックの剣を受け取る → 投擲 → 敵を攻撃／撃破 → 通貨獲得 → 次の剣を待つ。
- **ホーム**：難易度選択 → 強化解放・調整 → ゲーム開始。保存／ロードと音量調整、遊び方表示もある。
- **終了**：防衛ライン到達または撤退 → 結果表示 → ホームまたはリトライ。

難易度は Easy / Normal / Hard / Extreme / Nightmare の5段階で、すべて同じ `GameScene` を使用する。コード上の `GameMode` enum は `Normal` 一値であり、これらは別モードではなく `DifficultyLevel` の選択である。

## 4. プレイヤー体験を支える仕組み

### 入力と物理的な手応え

- **確認済み**：マウスとPointer向けのInput Systemバインディングがある。剣を操作領域から出さないクランプ、投擲速度上限、回転量上限を設けている。
- **確認済み**：投擲方向の更新には反応時間を使った指数補間 `1 - exp(-dt / reactTime)` を用いる。速度に比例した旋回角を積分し、飛行軌道を曲げる。
- **評価**：移動方向を直接即時変更するのではなく、回転操作を飛行方向へ時間的に反映する構造が操作の中心。端末ごとの体感や操作しやすさは実機検証なしに保証できない。

### 敵による判断

敵の挙動は共通の進行処理に加え、型別データと派生処理で差をつけている。例えば、カエルはジャンプ中だけ攻撃不可、トロールは設定方向の正面を防御、キノコは一定時間後に最大3体の胞子個体を生成する（値は現行アセット）。敵の詳細と注意点は [GameSpecification.md](GameSpecification.md) を参照。

### 成長と調整

攻撃力・投擲力・カーブ・反応時間・攻撃範囲・クリティカル・鍛造間隔・剣ストックが強化項目として定義される。強化購入は通貨を消費して解放し、投擲力・カーブ・反応時間・攻撃範囲は解放済み範囲内で上下調整できる。他の項目に同じ調整UIはない。

## 5. 魅力と差別化の客観評価

| 観点 | 評価 |
|---|---|
| 操作の独自性 | 回転量を軌道と攻撃間隔に使うため、操作と戦闘効果の対応がコード上明確。 |
| 敵の選択肢 | 対処条件の異なる敵が複数あり、軌道・タイミングを変える余地がある。 |
| 成長要素 | パラメータの強化と一部項目の調整により、プレイヤーが操作感を変えられる。 |
| 客観的な制約 | スポーン確率の選択式に不整合があり、データ上の出現重みが実際の分布に反映されない。現状では敵の多様性がデータ意図どおり保証されない。 |
| 未確認 | 競合作比較、ユーザーテスト、難易度曲線のプレイテスト、操作評価、収益・継続率。 |

## 6. プレイヤーに提示する説明の推奨

「剣をドラッグして回転量を作り、離す方向と回転量で攻撃軌道を操作する防衛サバイバル。敵ごとに攻撃可能な条件が異なるため、投擲の角度とタイミングを見極める。戦闘後は報酬で装備パラメータを解放・調整できる」と説明すれば、実装確認済みの範囲を超えない。
