# SwordSlicer ゲームデザイン

## 1. ゲームコンセプト

プレイヤーが剣をドラッグ操作して回転量と投擲方向を作り、投擲後の軌道と攻撃テンポを制御する防衛サバイバルゲーム。敵の位置と行動に応じたタイミングと軌道の選択を要求する。

## 2. ゲームプレイの流れ

1. 剣の近くを長押ししてドラッグを開始
2. 剣を円運動などで移動させ、回転量を蓄積
3. ドラッグ終了時の位置から投擲方向を算出
4. 投擲後の飛行中、蓄積した回転量に応じて軌道が滑らかに変化
5. 攻撃周期で周囲の敵を判定し、敵撃破で報酬獲得
6. 敵の出現頻度が増加する中で防衛ラインを守る

## 3. ゲームメカニクス

### 剣の投擲と軌道制御

- 投擲方向：ドラッグの最後0.1秒間の位置変化から決定
- 投擲速度：ドラッグ継続時間に応じて計算
- 軌道：蓄積した回転量を時間依存で反映し、滑らかに変化
- 寿命：投擲から5秒後に自動破棄

### 敵との対処

敵ごとに異なる対処条件がある：

- 敵の多くは継続的に防衛ラインへ移動
- ジャンプ中は攻撃不可の敵（カエル）
- 正面からの攻撃を防ぐ敵（トロール）
- ダメージ後に無敵状態となる敵（ゾンビ）
- 胞子で増殖する敵（キノコ）

### 強化と成長

以下の要素を通貨で強化できる：

- 攻撃力、投擲力、軌道カーブ、反応時間、攻撃範囲、クリティカル率・ダメージ、鍛造間隔、剣ストック上限

投擲力・軌道カーブ・反応時間・攻撃範囲は解放済み範囲内で上下調整可能。他の強化はレベル上昇式。

## 4. ゲーム進行と難易度

難易度は 5 段階で選択：Easy / Normal / Hard / Extreme / Nightmare。難易度ごとに敵のステータス倍率と出現速度が異なる。

ゲーム中は時間経過とともに敵の強度が上昇し、新しい敵種が順次解放される。
