# SwordSlicer ゲーム仕様

## 1. 操作

| 入力 | 動作 |
|---|---|
| 剣の近くで押下 | ドラッグ開始。押下可能領域は剣の中心から攻撃範囲内。 |
| ドラッグ | 入力座標をワールド座標に変換し、操作エリア矩形内にクランプして剣を追従させる。 |
| リリース | ドラッグ差分から投擲方向を決定。方向がほぼゼロの場合は上向き。ドラッグ時間から速度を計算。 |
| 「剣を取る」ボタン | ストック中なら剣を生成。投擲済みの剣がある場合のみ実行可能。 |

Input Actionは `Point`（Vector2）と `Press`。Mouse と Pointer の位置・押下バインディング対応。

## 2. 戦闘ルール

- 投擲後の剣は操作不可・帰還なし。投擲から5秒後に破棄。
- 攻撃間隔：`max(minInterval, baseInterval - abs(rotateAmount) * 0.01)`。基準0.25秒、最小0.01秒。
- 攻撃判定は `Physics2D.OverlapCircle` で単一敵を検索。範囲内の全敵一斉攻撃ではなく、見つかった敵1体へのみダメージ。
- 敵が検出範囲内にない場合、攻撃状態が継続するため毎フレーム検索が続く。
- 敵が攻撃防止状態（`CheckAttackable` = false）の場合、ミス表示後に攻撃周期をリセット。可能な敵にはダメージ付与。
- 基礎攻撃力：`(1 + 0.5 * 攻撃力レベル) × 剣倍率`。クリティカル率：`Clamp01(0.1 * レベル)`。クリティカル倍率：`1 + 0.2 * レベル`。
- 命中時に効果音、カメラシェイク、エフェクト生成、ヒット数更新。ヒット数はSwordAttackインスタンス単位で追跡し、最大値を結果に記録。

## 3. 剣のストック・強化

- 最大ストック：5本。初期上限1本。上限値：`1 + ストックレベル`（最大5）。
- 剣種：Normal（確率0.6） / Advanced（0.3） / Ultimate（0.1）。ストック追加時に種別を抽選。
- 鍛造間隔：基準5秒にレベル倍率を適用。
- 強化対象：攻撃力、投げる力、曲がる力、曲がる反応時間、攻撃範囲、クリティカル率、クリティカルダメージ倍率、鍛造間隔、ストック数。
- 投げる力・曲がる力・曲がる反応時間・攻撃範囲は解放レベル範囲内でレベル調整可能。その他は購入時にレベルが上昇。
- 購入価格は `BattleSettingConfig.Upgrades.cs` のコード定義。

## 4. 敵・敵出現

敵種は10種（スライム2、ゴブリン2、ゾンビ、カエル、トロール、ミノタウロス、キノコ、デビル、火の玉）で `EnemySpawnScheduleSO` に登録されている。

| 敵 | 動作 |
|---|---|
| スライム2種 | 開始地点からターゲットへの線形移動。 |
| ゴブリン2種 | クールダウン後、ターゲット方向へ設定距離を移動。移動時にスプライト反転。 |
| ゾンビ | 残HP が直前基準の30%以下で3秒無敵。無敵中は攻撃不可・移動停止。 |
| カエル | クールダウン後、ターゲット方向へジャンプ。ジャンプ中は攻撃不可。 |
| トロール | 正面方向からの攻撃を防止。正面からの角度が90度以上なら側面・背面攻撃を許可。判定結果を0.5秒固定。 |
| ミノタウロス | ゴブリン基底処理を使用。個別DataSO参照。 |
| キノコ | 非胞子個体は遅延後に1回繁殖（3体生成）。胞子個体は5秒後に移動可能、再繁殖しない。 |
| デビル | 定位置で10秒ごとに火の玉3体を生成。 |
| 火の玉 | デビルから生成。設定振幅・周期の正弦波でY方向に揺れながら移動。 |

敵は出現位置・ターゲット・時間依存ステータス倍率で初期化される。防衛ラインのY座標に到達時（±0.1以内）、ゲームオーバーを発火。

### 難易度と時間経過

難易度：Easy / Normal / Hard / Extreme / Nightmare。基礎ステータス倍率：0.8 / 1.0 / 1.2 / 1.5 / 2.0。難易度上昇間隔係数：1.2 / 1.0 / 0.8 / 0.6 / 0.2。

敵ステータス：`difficultyBase × 1.1^(elapsed / effectiveIncreaseInterval)`。スポーン間隔：`8 × 0.9^(elapsed / effectiveIncreaseInterval)`（最短0.25秒）。タイプ解放間隔：基準20秒に難易度係数を掛ける（最低5秒）。報酬：敵基本報酬に難易度基礎倍率を掛ける。

**既知制約**：スポーン抽選でデータ重みの合計が1を超えるため、後位エントリーの選出確率が低くなる。確率分布の正規化が必要。

## 5. ゲーム進行・結果・保存

- Scene遷移：HomeScene（index 0） → GameScene（index 1）。
- 難易度選択時に `EnemySpawnScheduleSO` の DifficultyLevel を設定後、GameScene をロード。
- ゲームオーバー：防衛ライン到達 または 撤退。結果画面へ遷移。
- 結果表示：難易度、ステージタイトル、防衛時間、敵撃破数、最大ヒット数、獲得通貨、剣生成数。Unityroom へ総獲得通貨を送信（Nightmare時は防衛時間も含める）。
- データ保存：ホームUIから手動実行。保存内容は強化レベル・通貨・音量。PlayerPrefs に JSON 形式で保存。

## 6. UI

- **ホーム**：ゲームモード選択、強化メニュー、保存／ロード、音量設定、遊び方。
- **ゲーム中**：剣ストック残数・生成進捗、剣パラメータ（速度・回転・カーブ）、経過時間、通貨、撤退ボタン、音量。
- **結果**：難易度・防衛時間・敵撃破数・最大ヒット数・獲得通貨・剣生成数、ホーム復帰・リトライボタン。

UI Toolkit（UXML/USS）でホーム・ゲーム中・結果・強化を構築。ダメージ・クリティカル・通貨ポップアップは TextMesh Pro uGUI Prefab を使用。
